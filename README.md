# Crevisto Homebrew Tap

Install the [Crevisto CLI](https://crevisto.com) — 100+ AI image tools from your terminal.

```bash
brew tap javimosch/tap
brew install crevisto
```

Then try: `crevisto tools` to list all 100 AI image tools, or `crevisto --help`.

- Website: https://crevisto.com
- Docs: https://crevisto.com/docs
- Source: https://github.com/javimosch/crevisto
